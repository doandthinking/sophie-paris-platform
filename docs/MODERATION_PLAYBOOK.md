# Moderation Playbook

## Queues

- Travel-buddy posts.
- Community events.
- Reviews.
- Reports.
- Provider applications.

## Actions

- Hide content.
- Pause profile placeholder.
- Block user placeholder.
- Add admin note.
- Mark high risk.
- Export incident record.
- Escalate for human handling.

## High-risk Signals

- Requests to meet at private homes.
- Hotel room disclosure.
- Real-time location disclosure.
- Requests for passport or bank card.
- Commercial solicitation.
- Harassment.
- Minor safety concerns.
