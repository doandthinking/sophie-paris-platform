Travel kits are scenario solution bundles, not paid bundles in the MVP.

Initial kits:

- 巴黎落地安心包.
- 手机被偷恢复包.
- 巴黎亲子安心包.
- 巴黎雨天包.

Each kit should show:

- Scenario.
- Included demo items.
- Recommended services.
- Official resources when relevant.
- Fulfillment mode.
- Manual confirmation.
- DEMO label.
- Add to trip board.
- Submit request.
