# Cross Sell Rules

V5 uses static recommendation rules only.

Rules:

- Do not claim real-time personalized AI.
- Do not collect sensitive data for recommendations.
- Show copy: `你可能还需要` and `根据当前场景推荐`.
- Make recommendations scenario-based.

Examples:

- Hotel -> airport transfer, arrival kit, eSIM.
- Seine cruise -> raincoat, dinner, photo shoot.
- Family -> stroller, kids raincoat, family restaurant.
- Stolen phone -> police process, eSIM, cable, anti-theft bag.
- Museum -> certified guide, nearby restaurant, luggage storage.
- Proposal -> evening dress, photographer, makeup, anniversary dinner.
- Departure -> luggage storage, tax refund guide, airport transfer, luggage scale.
