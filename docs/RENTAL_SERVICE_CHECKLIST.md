# Rental Service Checklist

Before rental services go live:

- Merchant agreement.
- Size/stock confirmation.
- Rental period options.
- Deposit amount and legal basis.
- Cleaning policy.
- Damage policy.
- Late return policy.
- Return location.
- Consumer complaint process.
- Insurance review when relevant.

MVP status: display and request only; no rent, no deposit, no stock promise.
